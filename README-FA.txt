آزمایش روی کامپیوتر:
1) پوشه را از ZIP خارج کنید.
2) بهترین روش: در همان پوشه یک ترمینال باز کنید و دستور زیر را اجرا کنید:
   python -m http.server 8000
3) در مرورگر وارد این آدرس شوید:
   http://localhost:8000
4) روی مهر پاکت کلیک کنید. موسیقی شروع می‌شود و سایت باز می‌شود.

آپلود روی GitHub با مرورگر:
1) وارد ریپازیتوری https://github.com/zeynab-kalhor/mina شوید.
2) روی Add file و سپس Upload files بزنید.
3) تمام محتویات پوشه mina_complete را بکشید و داخل صفحه رها کنید؛ خود پوشه اصلی را آپلود نکنید.
   یعنی index.html، پوشه assets و فایل‌های mobile.mp4، laptop.mp4 و music.mp3 باید در ریشه ریپازیتوری باشند.
4) پایین صفحه در Commit changes یک عنوان مثل «Final cinematic invitation» بنویسید.
5) روی Commit changes بزنید.
6) وارد Settings > Pages شوید.
7) در بخش Build and deployment گزینه Deploy from a branch را انتخاب کنید.
8) Branch را روی main و Folder را روی /(root) قرار دهید و Save بزنید.
9) چند دقیقه صبر کنید و صفحه را Refresh کنید تا لینک سایت نمایش داده شود.
